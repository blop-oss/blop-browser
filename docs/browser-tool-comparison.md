# Browser tool comparison

This matrix compares documented product contracts for agent-facing browser
tools. It is a capability review, not a benchmark or security audit. No reviewed
evidence establishes a single tool as the right fit for every workload.

Use browser automation only on websites, accounts, and data you own or are
authorized to access. Blop Browser's [acceptable-use policy](../ACCEPTABLE_USE.md)
applies to this project.

The Browser Use CLI and Browser Harness share one column because the reviewed
Browser Use CLI [delegates its browser commands to Browser
Harness](https://github.com/browser-use/browser-use/blob/6c73fced2f6d45a11d88622fe56365a5fe18f28b/browser_use/cli.py#L130-L202).
Browser Use's separate Python agent API is called out where it changes the
comparison. “Browser Harness” in this document means the Browser Use project,
not this repository's retained npm package name.

## Method

The review uses only first-party repositories at pinned commits. We reviewed
the documentation and implementation links below; we did not install or run the
other products. `Unknown / not tested` therefore means the reviewed primary
sources do not support a stronger claim. Absence from documentation is not
proof that a feature is impossible.

Every product cell links directly to the source for that cell. Links for other
projects include a full commit SHA and line range so later documentation changes
do not silently change this comparison.

## Selection notes

The products make meaningfully different tradeoffs:

- Playwright CLI has a broader Playwright debugging surface than Blop Browser,
  including arbitrary evaluation, trace capture, annotated video, and three
  Playwright engines. Its default profile is memory-only, which is convenient
  for cleanup but does not survive browser close.
- Playwright MCP fits existing MCP clients and provides rich introspection,
  multiple engines, trace/video tools, and a persistent workspace profile. That
  default profile conflicts when multiple clients share a workspace unless the
  caller opts into isolation or distinct data directories.
- agent-browser has the broadest documented operational surface in this review:
  dashboard, provider integrations, plugins, policies, state encryption, HAR,
  profiler, and multiple engines. Its evaluation surface is correspondingly
  broad, and the stronger domain containment mode cannot be combined with
  existing-profile attachment.
- Browser Use CLI and Browser Harness optimize for direct control of a person's
  logged-in Chrome, agent-editable helpers, and optional managed cloud browsers.
  That flexibility includes raw CDP, JavaScript, and Python execution; local
  parallel tasks share one browser, while isolation is a cloud workflow.
- Blop Browser emphasizes a smaller bounded tool contract, explicit existing-
  profile consent, inspectable profile ownership, deterministic disposal, and a
  TypeScript embedding API. It does not expose arbitrary evaluation or raw CDP,
  and it does not currently document Playwright trace/video export. It does not
  offer a managed cloud tier for this package.

Choose based on the browser engine, trust boundary, profile lifecycle,
integration protocol, and deployment model your host actually needs. Benchmark
task success, latency, and token use in your own workload before making a
performance claim.
