# Public claims and evidence

This inventory maps Blop Browser's release-facing promises to implementation,
tests, or a reproducible local proof. It is a maintenance ledger, not a product
ranking or a claim that the package completes browser tasks by itself.

For product selection, use the canonical
[positioning and local contract proof](positioning-proof.md) and
[browser tool comparison](browser-tool-comparison.md). This document does not
duplicate their positioning guidance or competitor matrix.

## Inventory scope

The inventory covers copy that a package user, repository visitor, coding
agent, contributor, or release reviewer can encounter. Claim IDs point to the
single matching row in the evidence ledger.

## Enforcement boundaries

The checker validates this inventory, direct line-anchored evidence, required
limitations links, and identified public claim sentences. It rejects specific
universal, superlative, undetectability, bypass, security, and performance
promises. It does not reject a quoted issue example, a historical result, or an
explicit negation such as “does not guarantee anonymity.”

When a material promise changes, update its existing row and every listed
surface. Add a new row only for a genuinely new promise; do not split one claim
across several marketing variants.
