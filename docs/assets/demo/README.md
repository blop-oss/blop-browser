# Demo asset directory

This directory reserves stable paths for the public Blop Browser demo. It
contains no synthetic placeholder image, so the README cannot render a broken
or misleading demo.

Follow [`../../demo-recording.md`](../../demo-recording.md) and the
[acceptable-use policy](../../../ACCEPTABLE_USE.md) to create and review the
assets. After recording, add these files:

- `blop-browser-demo.mp4`
- `blop-browser-demo-poster.webp`

Don't commit raw captures, authentication flows, cookies, private application
data, live-site access controls, consequential transactions, or unreviewed
exports.
